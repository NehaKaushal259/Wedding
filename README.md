## Wedding Planner Website

# About 
An elegant wedding planner website that has been created using 🌐HTML5, 🎨CSS3, and 🅱️Bootstrap.
This project is an assignment that was designed for practice on the frontend development concepts like designing websites, creating responsive sites, and styling the user interface.

The wedding planner website includes several pages related to weddings such as wedding services, vendors, clients, creative teams, blog, and contact us page.


# 🚀 Features
``` text
💍 Elegant Wedding Landing Page
🧭 Fixed Navigation Bar
🖼️ Hero Section with Background Image
🎯 Wedding Event Sections
🌸 Wedding Vendors Showcase
👥 Previous Clients Section
👨‍💼 Creative Team Cards
✉️ Contact Form UI
📰 Blog Section
✨ Hover Effects & Transitions
📱 Structured Frontend Layout
🎨 Fully Custom CSS Styling
```
